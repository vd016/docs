## Getting Started with SaaS Integrations

To start scanning for sensitive data in your SaaS applications, follow these basic steps:

<Steps>
  <Step title="Connect an Integration">
    Navigate to the **Integrations** tab in the Nightfall Dashboard and select the application you want to protect (e.g., Slack or Google Drive). Follow the OAuth prompts to authorize Nightfall.
  </Step>
  <Step title="Configure a Detection Policy">
    Create a new **Policy** to define what data you want to detect (like Social Security Numbers or Credit Cards) and what actions to take when a violation occurs (like sending an alert or redacting the message).
  </Step>
  <Step title="Review Violations">
    Once your policy is active, navigate to the **Events** dashboard. Here you can triage alerts, review the context of the exposed data, and take manual remediation actions if necessary.
  </Step>
</Steps>

## Getting Started with the Developer API

If you're building a custom integration, you can start scanning payloads immediately using our API.

<Steps>
  <Step title="Generate API Keys">
    Log into the Nightfall Dashboard, navigate to the **Developer** section, and generate a new API Key. Keep this key secure and store it in an environment variable (`NIGHTFALL_API_KEY`).
  </Step>
  <Step title="Send a Scan Request">
    Use one of our language-specific SDKs (Python, Go, Node.js, Ruby, Java) or make a direct HTTP request to the `/v3/scan` endpoint.

    ```bash
    curl -X POST https://api.nightfall.ai/v3/scan \
      -H "Authorization: Bearer $NIGHTFALL_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "payload": ["My credit card number is 4000-0000-0000-0000"],
        "policy": {
          "detectors": [
            { "name": "Credit Card Number" }
          ]
        }
      }'
    ```
  </Step>
  <Step title="Process the Results">
    The API will return an array of findings, including the exact location of the sensitive data, the confidence level, and the specific detector that was triggered.
  </Step>
</Steps>
