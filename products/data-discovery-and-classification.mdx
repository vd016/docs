# Data Discovery & Classification

Nightfall now provides **Data Discovery and Classification** for cloud storage solutions and CRM tools such as Microsoft OneDrive, Google Drive, and Salesforce.

<img src="https://cdn.prod.website-files.com/636966d8ae15afa96e899d52/638fc3e586e482d6edc55634_webclip%20256x256%20(2).png" alt="Data Discovery Icon" width="100"/>

## Overview

Scan historic data to detect sensitive data exposed on public platforms. Identify where sensitive data lives across cloud storage and CRM before it moves - enabling proactive remediation rather than reactive event response.

### Key Benefits

* **Identify Sensitive Data**: Automatically discover PII, PHI, PCI, API keys, and other sensitive information across your environment.
* **Proactive Remediation**: Address potential data leaks by classifying data *before* it leaves your secure environment.
* **Continuous Scanning**: Nightfall scans historically stored files and data as well as continuously monitoring for newly ingested information.
* **Context-Aware Classification**: Nightfall uses advanced machine learning to not just find keywords, but to understand the context, reducing false positives.

<Tip>
By starting your deployment with a Data Discovery scan, you can immediately identify the highest-risk data sitting in your environment and take action.
</Tip>

## Setting up Data Discovery

To use Data Discovery across your cloud applications:
1. Connect your integration (e.g., Google Drive, OneDrive, Salesforce) from the Nightfall dashboard.
2. Select the **Historical Scan** or **Discovery** option in the integration settings.
3. Configure your detectors (e.g., Credit Card Numbers, Social Security Numbers, API Keys).
4. Run the scan and review the results in the **Findings** tab.

<Note>
Depending on the volume of your historical data, the initial discovery scan may take some time to complete. Once finished, ongoing detection will happen in real-time.
</Note>
