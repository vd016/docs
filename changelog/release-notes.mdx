# Release Notes

Welcome to the Nightfall Release Notes. We regularly update our platform to provide better security, usability, and visibility.

## August 2026

* **Nightfall AI Copilot (Nyx) Beta**: We've launched Nyx, our autonomous DLP analyst, giving you a natural-language interface for investigating exfiltration risks.
* **New MCP Integrations**: Introduced visibility into AI agents and coding assistants via Model Context Protocol (MCP), enabling strict AI governance.
* **API v3 Launch**: The new REST API v3 is now generally available.

## July 2026

* **OneDrive & Salesforce Data Discovery**: Added robust data classification options across major CRM and cloud storage apps. 
* **Enhanced Role-Based Access Controls (RBAC)**: Admins can now create granular roles down to specific integrations and endpoints.
